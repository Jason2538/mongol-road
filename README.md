# 몽골 로드 (MVP)

몽골 초원의 길을 오토바이로 달리며 풍경을 즐기는 1인용 웹 라이딩 게임. 서버 없이 정적 사이트로 동작합니다.

## 로컬 실행
Node.js 18 이상이 필요합니다.

```
npm install
npm run dev
```
터미널에 나오는 `Local:` 주소(예: http://localhost:5173)를 브라우저로 엽니다. 같은 와이파이의 휴대폰에서는 `Network:` 주소로 접속해 모바일을 시험할 수 있습니다.

## 조작
| 동작 | PC | 모바일 |
|---|---|---|
| 가속 / 브레이크 | W·↑ / S·↓·Space | 화면의 가속 / 브레이크 버튼 |
| 조향 | A D · ← → | 화면의 ◀ ▶ 버튼 |
| 크루즈(40/60/80/100) | Q | 상단 "크루즈" |
| 시점 변경 | C | 상단 "시점" |
| 설정 / 일시정지 | Esc | 상단 "설정" |

게임패드도 지원합니다(스틱=조향, RT=가속, LT=브레이크, A=크루즈, Y=시점).

## GitHub Pages로 배포 (Git 없이)
1. GitHub에서 새 저장소를 만듭니다 (예: `mongol-road`, Public).
2. 저장소 화면에서 **Add file → Upload files**로 이 폴더의 파일을 올립니다. `node_modules`, `dist` 폴더는 올리지 않습니다. 숨김 폴더 `.github`도 반드시 함께 올립니다(폴더째 끌어다 놓기).
3. **Settings → Pages → Build and deployment → Source** 를 **GitHub Actions**로 바꿉니다.
4. 올릴 때마다 자동으로 빌드·배포됩니다. 주소는 `https://<아이디>.github.io/mongol-road/` 입니다.

Git이 설치되어 있다면 `git push`만 해도 같은 방식으로 배포됩니다(기본 브랜치 이름은 `main`).

## 폴더 구조
```
index.html        화면 뼈대(계기판, 버튼, 설정창)
src/main.js       게임 루프, 카메라, 설정, 화면 연결
src/road.js       끝없는 도로 생성, 노면 종류
src/world.js      청크 지형·도로 메시, 하늘, 구름, 먼 산, 전신주, 바위
src/bike.js       오토바이 물리(속도, 기어, 기울기, 미끄러짐)와 로우폴리 모델
src/input.js      키보드·터치·게임패드
src/audio.js      엔진·바람·노면 소리 합성
```

## 사용한 외부 자료
| 자료 | 용도 | 라이선스 |
|---|---|---|
| [three.js](https://threejs.org) | 3D 엔진 | MIT |
| [Vite](https://vitejs.dev) | 빌드 도구 | MIT |

이미지, 3D 모델, 음원 파일은 사용하지 않았습니다. 모든 그래픽과 소리는 코드로 생성합니다.

## 알려진 한계 (MVP)
- 앞/뒤 브레이크는 하나로 합쳐져 있음, 낮 시간대만 지원, 사진 모드와 배경음악 없음
- 도로 폭(7m)과 중앙 점선은 임의 값. 실제 몽골 기준은 아직 확인하지 못함
- 지형은 자동 생성(실제 SRTM/DEM 데이터는 미사용)
